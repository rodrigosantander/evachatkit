📋 Instrucciones de Gestión

  • Contraseña Compartida: Todos los usuarios usan la misma contraseña configurada en las variables de entorno
  • Usuarios Individuales: Cada usuario tiene su propio username/password
  • Agregar Usuarios: Edita el archivo generate-user-hashes.js y ejecuta el script
  • Variables de Entorno: Configura EVA_PASSWORD_HASH y AUTH_SALT en Netlify
  • Sesiones: Duran 24 horas y se almacenan localmente en el navegador

🔧 Comandos para Gestión de Usuarios

Para generar hashes de nuevos usuarios:

node generate-user-hashes.js

Para generar contraseña compartida:

node generate-password-hash.js
